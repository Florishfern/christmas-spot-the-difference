ตั้งค่า Cloud Database เพื่อเชื่อมต่อผู้เล่นทุกคน (Vercel & GitHub)

เมื่อนำเว็บนี้ขึ้น GitHub และ Deploy ที่ Vercel ผู้เล่นจะเล่นผ่านโทรศัพท์และคอมพิวเตอร์หลายเครื่อง การใส่ Firebase Realtime Database (ฟรี 100%) จะทำให้ข้อมูลคะแนนและด่านของผู้เล่นทุกคน วิ่งมาอัปเดตบนแดชบอร์ดนี้แบบเรียลไทม์ทันทีโดยไม่ต้องเขียนโค้ดหลังบ้านเลยครับ!

📌 3 ขั้นตอนในการเปิดใช้งาน Firebase ฟรี:
1. เข้าไปที่ console.firebase.google.com แล้วกด Create Project
2. ไปที่เมนู Build > Realtime Database กด Create Database แล้วเลือก Rules: read: true, write: true
3. ไปที่ Project Settings ก๊อปปี้ firebaseConfig มาวางในช่องด้านล่าง แล้วกดบันทึก
