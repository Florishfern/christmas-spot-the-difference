# 🎄 เกมจับผิดภาพธีมคริสต์มาส ระดับยากพิเศษ (Christmas Spot The Difference - Hard Mode)

## ✨ ไฮไลต์ฟีเจอร์เด่น (Key Features)

### 🎮 ระบบการเล่น (Gameplay)
- **ครบ 5 ด่าน 40 จุดต่างสุดแนบเนียน:** ภาพวาดเวกเตอร์ SVG ความละเอียดสูง สไตล์นิทานคริสต์มาสขอบทองหรูหรา
  1. **ด่านที่ 1:** ห้องนั่งเล่นเตาผิงคืนคริสต์มาสอีฟ (Cozy Fireplace Eve)
  2. **ด่านที่ 2:** โรงงานของเล่นคุณลุงซานต้า (Santa's Magical Toy Workshop)
  3. **ด่านที่ 3:** หมู่บ้านขนมปังขิงหิมะหวาน (Gingerbread Candyland)
  4. **ด่านที่ 4:** คอกกวางเรนเดียร์ขั้วโลกเหนือ (Reindeer Barn at North Pole)
  5. **ด่านที่ 5:** เลื่อนเหาะราตรีข้ามฟากฟ้าคริสต์มาส (Santa's Midnight Sleigh Flight)
- **Hard Mode Rules:**
  - ตัวจับเวลานับถอยหลัง 90 วินาที/ด่าน
  - คลิกเจอจุดต่างได้โบนัสเวลา **+5 วินาที**
  - คลิกพลาดโดนหักเวลา **-5 วินาที** พร้อมแอนิเมชันกรอบภาพสั่นเตือน
- **🔍 แว่นขยายส่องจุดจิ๋ว (Magnifier Loupe):** เลนส์แก้วขอบทองซูม 2.2x เลื่อนตามเมาส์/นิ้วสัมผัส
- **🔎 โหมดขยายภาพรวม (Zoom Frame 1.35x):** เหมาะสำหรับการเล่นบนแท็บเล็ตและมือถือ
- **💡 คำใบ้เวทมนตร์เอลฟ์ (Elf Magic Hint):** ส่งคลื่นเรดาร์สีทองนำทางไปยังจุดต่าง (3 ครั้ง/ด่าน)
- **⭐ ระบบจัดอันดับ 1 - 3 ดาว:** คำนวณจากเวลาที่เหลือ ความแม่นยำ และจำนวนคำใบ้
- **🎵 ระบบเสียงสังเคราะห์ในตัว (Web Audio API):** ไม่ต้องพึ่งพาไฟล์เสียงภายนอก โหลดเล่นได้ทันที พร้อมเพลงบรรเลง BGM สบายหู

### 📊 แดชบอร์ดผู้จัดงาน & ประกาศรางวัล (Admin Dashboard)
- **สรุปสถิติสดแบบเรียลไทม์:**
  - 👥 ผู้เล่นทั้งหมดกี่คน
  - 👑 ผ่านครบ 5 ด่านแล้วกี่คน (ผู้มีสิทธิ์ลุ้นรับรางวัล)
  - ⏳ ผู้เล่นที่กำลังลุยด่าน
  - ⚡ สถิติเวลาที่พิชิตได้เร็วที่สุด
- **ตารางความคืบหน้านักสืบทุกคน:** แสดงชื่อเล่น, ชื่อกลุ่ม, ด่านปัจจุบัน, แถบความคืบหน้า (Progress bar), ดาวสะสม, เวลารวม และ **Timestamp วัน/เวลาที่พิชิตเสร็จ**
- **📥 ส่งออกข้อมูลเป็นไฟล์ Excel (CSV):** ดาวน์โหลดตารางรายชื่อและผลการแข่งขันเป็นไฟล์ `.csv` รองรับภาษาไทย 100%
- **🎁 ระบบสุ่มจับรางวัล (Lucky Draw / Raffle Spinner):**
  - คัดกรองเฉพาะผู้ที่ผ่านครบ 5 ด่านเข้าสู่โถสุ่มรางวัล
  - หมุนสุ่มชื่อผู้โชคดีพร้อมเอฟเฟกต์พลุ Confetti และเสียงปรบมือ
  - กดคัดลอกรายชื่อผู้ได้รับรางวัลไปแชร์ลงกลุ่ม LINE หรือโพสต์ประกาศผลได้ทันที
- **🗑️ ปุ่มล้างกระดานเริ่มแข่งใหม่:** รีเซ็ตข้อมูลกระดานแข่งขันทั้งหมดเพื่อเริ่มกิจกรรมรอบใหม่ได้ด้วยคลิกเดียว

## 🚀 วิธีนำขึ้น Vercel (Deployment)

1. นำ Repository นี้เชื่อมต่อกับ [Vercel](https://vercel.com)
2. กด **Deploy** ได้ทันทีโดยไม่ต้องตั้งค่า Build Settings ใดๆ (เป็น Static Web Application)
3. เมื่อเปิดหน้าเว็บบน Vercel แล้ว ให้ผู้จัดงานเข้าไปที่ **`📊 แดชบอร์ด` > แท็บ `⚙️ เชื่อมต่อคลาวด์ดาต้าเบส`**
4. นำ `firebaseConfig` จาก Google Firebase Realtime Database (ฟรี 100%) มาวางในช่อง เพื่อเปิดใช้งานระบบ Realtime Sync ทั่วโลก
